# University Club & Event Management System

A desktop-based **University Club & Event Management System** for managing university clubs, students, events, memberships, registrations, and attendance.

## Project Overview

The system will provide a centralized application for managing university club activities and events.

Students will be able to explore clubs and events, join clubs, and register for events. Club organizers will be able to manage clubs and events, while administrators will be able to manage the overall system.

## Planned Features

* User registration and login
* Student management
* Club management
* Club membership management
* Event creation and management
* Event registration
* Event capacity management
* Attendance management
* Certificate management
* Search and filtering
* Reports and analytics

## User Roles

### Student

* Register and log in
* Browse clubs
* Join clubs
* Browse upcoming events
* Register for events
* View registered events
* View attendance
* View certificates

### Club Organizer

* Manage club information
* Create and manage events
* View event registrations
* Manage attendance
* Manage certificates

### Administrator

* Manage students
* Manage clubs
* Manage organizers
* Manage events
* View reports
